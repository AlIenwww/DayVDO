# macOS 27 兼容适配验收

日期：2026-09-21。保留四个页面、现有待办外观与数据格式，最低部署版本仍为 macOS 15。未提交或推送 Git，未覆盖已安装应用，全部写入测试均使用独立数据。

## 修复与证据

旧安装包和旧构建的 Mach-O `LC_BUILD_VERSION` 均为 `minos 15.0 / sdk 15.0`。在 Xcode 27 下明确指定 SDK 27 的干净 SwiftPM 构建仍复现该记录；直接 swiftc 编译的小型探针则正确记录 SDK 27。构建入口因此向链接器明确传递实际 SDK 与部署版本：`-platform_version macos 15.0 27.0`，并在打包前后核对 Mach-O。没有修改成品二进制冒充 SDK。

正确链接后，系统自动提供新版窗口按钮、工具栏和侧栏外观，标题栏与内容边界对齐。未加入窗口按钮定位、固定像素偏移、私有 API 或全局窗口补丁。遵循 Apple 的 [SwiftUI 更新说明](https://developer.apple.com/videos/play/wwdc2026/269/) 与 [AppKit 更新说明](https://developer.apple.com/videos/play/wwdc2026/289/)。

实际检查另发现语言切换后侧栏 List 仍保留原语言。现按语言更新侧栏容器身份，外部选择状态继续保留；八种语言切换已复验。没有新增 macOS 27 专用 UI API。

新增 AppDataLocation 隔离策略：只有显式测试标记与专用测试 bundle ID 同时满足时才使用独立目录，Debug 和 Release 均适用。普通应用的数据路径与迁移规则保持原样。
