# 0.8.1 全项目优化与验证

测试日期：2026-10-24；最终记录核对：2026-10-25。改动保留在工作区，未提交、推送或发布。测试均使用临时合成数据。

## 修改范围

- 数据查询：维护按任务、日期、项目建立的索引；仅在相关集合改变时重建。复用排序、项目进度、安排分钟数，保留稳定排序、撤销、任务关联和跨午夜规则。
- 持久化：从 `TodoStore` 分离编码快照和文件写入职责。防抖结束后才取得快照；相同内容不重复写盘；保存序号同时保护界面状态和实际写入顺序。并发刷新继续保存最新编辑。备份目录元数据每轮只读取一次，保留原子写入、最多五份自动备份和损坏文件恢复流程。重复项目／标签 ID 进入损坏数据恢复流程，避免索引构造崩溃。
- 日历：窗口内的日期和周边界只计算一次；同一批筛选共享相对日期范围；跨周卡片裁剪跳过多余日期换算。拖动仍实时预览，但同一天内移动指针不重复发布相同日期范围；每周溢出数量按列一次统计。
- 页面与原生控件：共享日期刷新时钟和通知源；统一窗口键盘监听的注册／注销；加载提示和项目折叠任务随视图取消；滚动动画失去拥有者后停止定时器。编辑器原生弹出菜单只在标题、符号、颜色或外观变化时重建图标，语言资源 Bundle 按语言复用。清理重复判断和未使用类型。
- 0.8.1 交互：点击时间线空白处（含刻度区）取消安排选中；总待办子任务使用系统拖动预览，经过目标时实时让位、轻微回弹，并遵守减少动态效果设置。悬停仅改变临时顺序，放下才保存一次，取消恢复。

审查覆盖数据模型、存储、今日待办／总待办／日历／设置、编辑器、原生桥接控件、资源和构建入口。现有数据格式仍为版本 4，没有增加第三方依赖；月视图实验开关和已有手势策略保持原状。

## 可重复性能负载

同一台 Mac、同一 Debug 配置，使用 `OptimizationPerformanceTests`。日历覆盖 210 天，每组运行 7 轮、每轮构建 5 次，报告每次构建的中位耗时。读取组每轮进行 200 组项目任务、日期安排、已安排分钟数查询，报告整轮中位耗时。

基线为本轮较早保留的源码副本 `/tmp/dayvdo-081-baseline`，已包含当时的 0.8.1 交互改动，早于本轮索引与后续结构优化。它不是未经修改的 0.8.0 发布版。两版顺序执行相同测试集合，没有同时运行性能负载。

| 数据量 | 日历构建，之前 → 之后 | 200 组重复查询，之前 → 之后 |
| ---: | ---: | ---: |
| 100 条 | 3.49 → 1.71 ms | 119.46 → 0.25 ms |
| 1,000 条 | 41.92 → 20.25 ms | 1,498.27 → 0.26 ms |

查询负载刻意反复读取同一数据，展示的是缓存命中收益，不代表所有操作都会获得同样提升。它没有测量修改时的索引重建成本。上述结果不是显示器 FPS、完整切页延迟或耗电量测量，不能据此声称续航增加某一比例。

原生窗口渲染负载也运行了 100／1,000 条样本：横向滚动和时间线位置断言通过，1,000 条日期卡片滚动位置断言通过。1,000 条窗口的横向／日期区／时间线更新 p95 分别为 22.28／59.46／33.80 ms，仍存在明显峰值，不代表已经达到逐帧无卡顿。此次没有相同权限和环境下的旧版渲染对照，因此不据此计算 UI 提升百分比。

## 验证记录

- **最终完整测试：291 项全部通过，0 失败、0 跳过**，包含两项显式启用的计算／渲染负载。已核对源码和测试文件在此轮成功后没有变化，文件校验清单与 `full-verified.log` 一并保存在本地日志目录。

- 首次完整测试：289 项，288 通过、1 项失败，没有跳过。失败为 `CalendarWeekScrollWindowTests.testSlowNativeGestureMovesOneDayAndVerticalScrollStaysInItsPane`，一次零位移结束事件未被接受；其他位置和内容断言通过。
- 该用例在优化前副本、当前源码的独立对照运行中都通过。第二次全量运行（290 项）再次失败；诊断记录显示系统 `pressedMouseButtons == 1`，合成滚轮输入混用了真实鼠标按键状态。测试现将按钮状态作为合成输入一起提供，并增加“按住鼠标必须拒绝滚动、释放后接受”的独立用例。产品入口默认仍读取系统按钮状态，所有原有位移／事件处理断言保留。
- 覆盖新增的索引失效、撤销／重做、并发保存、相同内容不写盘、备份保留／恢复、重复 ID 检查、夏令时／周起点、日期筛选、原生键盘监听、时间线空白取消选中、拖动排序与拖放目标注册，以及已有八语言窗口尺寸、深浅色、滚动、缩放、编辑与持久化测试。
- 原先受限沙箱下多项窗口测试失败；允许测试进程正常连接 macOS 窗口服务后，除了上述偶发滚动用例，其余均通过。测试没有删除或放宽失败断言。
