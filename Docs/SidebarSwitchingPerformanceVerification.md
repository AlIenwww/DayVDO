## 实施与原因

### 原生侧栏

保留 `NavigationSplitView` / 原生 `List` 选中更新及按语言设置的 `.id(store.settings.language)`。SwiftUI Instruments 中四个侧栏 `ForEachChild` 条目只在采集开始时出现，随后切换未观察到相同条目反复新增；辅助功能条目标识也保持稳定。当前证据不支持把闪烁直接归因于每次点击重建侧栏，但不排除 Liquid Glass 内部选中动画或绘制更新。因此没有冻结按钮外观。

### 总待办

顶层采用 `LazyVStack`，项目自然展开高度按项目 ID 和宽度缓存。数据版本、搜索、筛选、显示已完成、日期、语言或字体尺寸变化时使高度缓存失效；保留折叠动画和滚动状态。

### 月视图

- 虚拟周范围从 `-1040...1040` 缩至 `-104...104`，保留 30 周数据缓存和接近边缘后的重新定位。
- 所有周行等高，因此 `ScrollPosition(y:)` 可以直接按行高定位；移除 `.scrollTargetLayout()` 和重复行 `.id`，避免解析所有虚拟周的滚动目标。仍为平铺等高行，没有使用曾导致定位回归的嵌套首尾占位方案。
- 跳过初始不足六个日期表头的无效视口，减少重复构建。
- 视口高度改变时重建时间轴并从外部会话恢复顶部周。
- 修复恢复日期位于中午、月份锚点位于午夜造成的周数少算；统一按日历日计算，包含正反向、跨年和夏令时测试。
- 远距离跳转显式更新月份标题与保存的顶部周，避免逻辑行仍为 0 时没有几何回调而残留旧标题。

### 周视图与语言

当前周的安排 ID 映射及每天布局结果按周、数据版本、显示已完成设置缓存。拖动预览实时计算，不覆盖静态缓存。设置页语言切换时同步刷新外观和默认重要度选择器。

未改变公开接口或用户数据格式。产品代码没有加入性能探针或测试数据路径改动。

## 计时方法与限制

独立 Release 包采用 100 或 1,000 条合成待办（5 个项目；分别 25、250 条安排）。临时探针记录本地 `NSEvent.timestamp`、SwiftUI selection 变化、详情背景 NSView 更新及其后的首个 `NSWindow.didUpdateNotification`；另记录月网格 `onAppear`。使用系统单调时钟，不包含工具调用往返时间。最终计时在编译和测试完成后采集。

窗口更新通知及 onAppear 不证明合成器已把目标帧显示到屏幕；selection 变化也不等于玻璃高亮像素出现。样本较少，可能受探针文件写入、辅助功能读取及系统负载影响，不是 p95，也不能据此宣布精确首帧达标。

## 2026-09-29 菜单反馈调整与当前交接状态

在追加需求后，将原生侧栏选中状态与详情呈现目的地分开：侧栏自身观察选中状态，详情观察已呈现目的地。第一次窗口更新监听在选中回调内同步登记，避免异步任务错过该次通知。快速改选会取消旧请求，保留最后一次选择；仍保留原生 List 和语言 `.id`。

进入日历时提前请求当前月窗口或当前周缓存。尝试等待缓存、提前设定滚动位置或在 onAppear 完成初始定位，后两类方案造成明显延迟；已按用户的条件撤回。最终方案不等待数据，不保证全部任务与网格严格同帧出现。
