## 实现

- 主筛选页的所属项目、标签改为摘要入口，移除两个限高的内嵌滚动列表。摘要依次为“不限”、单项名称、“已选 N 项”，完整名称通过辅助功能及悬停提示提供。

- 搜索按名称匹配、忽略大小写并去掉首尾空白；不改变隐藏条目的选择。重新打开清空搜索。项目维持名称排序，标签维持原排序与颜色。
- 点选立即更新原筛选绑定，连续多选保持面板打开。单一类别状态控制两个子面板互斥；关闭保留选择，Esc 优先关闭子面板。类别清除保留其他类别，清除全部沿用现有逻辑。
