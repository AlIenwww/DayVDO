# 操作手感对照

构建：`bash Tools/InteractionLab/build.sh`；打开 `dist/DayVDO-InteractionLab.app`。

选择一个算法，在同一区域分别切换「原有算法」和「候选算法」操作。
- 吸附：靠近虚线后轻微反向，观察是否反复脱离。
- 排序：拖过相邻行，再慢慢反向；Esc 应恢复开始时顺序。
- 边缘滚动：在浅蓝边缘区不同深度停留，比较速度与微调能力。
- 缩放：上下拖动或触控板缩放，快速反向；观察固定 08:00 锚点。

这是 AppKit 实际输入驱动的隔离算法实验，不读取或写入待办数据。排序示例未复制正式应用的 SwiftUI 回弹动画，因此不能用它评价正式应用的动画流畅度。旧缩放在显示回调中模拟固定步进，不是对旧任务调度器的性能复刻。系统开启减少动态效果时缩放直接到达目标。

候选算法未启用到正式应用；正式应用现有轻微回弹保持原样。
